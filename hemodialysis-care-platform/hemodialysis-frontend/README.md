# سامانه پایش دیالیز — فرانت‌اند

## راه‌اندازی

```bash
npm install
npm run dev
```

## ساختار پروژه

پروژه بر اساس معماری Feature-based سازمان‌دهی شده است.

## دستورات

- `npm run dev` — سرور توسعه
- `npm run build` — ساخت نسخه تولید
- `npm run lint` — بررسی کد
- `npm run format` — فرمت‌بندی کد
- `npm run type-check` — بررسی تایپ‌ها
